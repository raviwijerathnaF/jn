This tool visualizes the CSS custom properties from index.html and assets/pages.css. Use it to verify WCAG AA contrast and brand consistency. Toggle theme to see dark / light tokens.

How to use

--bg, --bg-2, --card, --line, --ink, --text, --muted, --cyan, --green, --blue, --navy, --btn-bg, --btn-fg, --err

- Dark theme defined in :root
- Light theme overrides in [data-theme="light"]
- Contrast checked by tools/check-contrast.py (126 pairs)
- This preview helps designers verify brand colors before publishing via SITE.pricing, SITE.proof, etc.

For booking embed: add your Calendly / Cal.com URL to SITE.booking.default — CSP frame-src already allows calendly.com and cal.com.
